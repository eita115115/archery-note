## 2. だれに、どんな声で書くか

**読む人**: 射線に立っているアーチャー（片手に弓、日なた、次の矢までの数秒）と、家でノートを見返しているアーチャー。
どちらも統計の授業は受けに来ていない。知りたいのは「いま何点か」「どこに集まったか」「サイトを触るか」「前と比べてどうか」。

**声**: クラブの経験のある先輩やコーチが、となりで短く教えてくれる感じ。相手を一人前の射手として扱う。

- 親切に、ふつうの言葉で、短く。
- ほめちぎらない。説教しない。言い訳を並べない。
- 分からないことは「まだ分かりません」と素直に言い、いつ分かるかを添える。

## 3. 文の決まり

1. **1文に1つのこと。** 2つ目は次の文か、たたんだ中へ。
2. **射手にとって大事なことから書く。** 「何が起きたか」「どうすればいいか」が先。アプリがどう計算したかは後ろか、たたんだ中。
3. **アプリの実況をしない。** 「〜は出していません」「〜と数えています」ではなく、射手の側から書く。
   例: 「グループRMSは計算していません」→「矢が3射になると、グルーピングが出ます」。
4. **数字は射手が使う単位で。** cm・秒・点・射・クリック・目盛り。割合（%）は、言って自然なときだけ（「72射のうち」など）。
   画面の点の数（px）、決定係数、σ、小数3桁は本文に出さない。
5. **小数は、動かせる細かさまで。** 点は整数か小数1桁、cm は小数1桁、秒は小数1桁。
6. **かっこ書きは短く。** 補足が長くなるなら、文を分けるか「詳しく」に入れる。
7. **打ち消しを重ねない。** 「区別できません」→「ほぼ同じです」。「〜とは限りません」→「〜とは言い切れません」を1回だけ。
8. **見出しは、射手がたずねる言葉で。** 「そろい方」→「毎射そろっているか」。「この回」→「この撮影」「この練習」。
9. **です・ます。** 感嘆符は使わない。ボタンは動詞で終える（「記録を始める」「ゴミ箱へ移す」）。
10. **射手の状況を名詞にしない。** 「寄り」「上下」「ずれ」「不確かさ」「当てはまり」「まとまり方」を名詞として本文に書かず、矢や点数が何をしたかを動詞で言う。
    図や欄の名前（「サイト 上下」「左右の広がり」「矢の中心」）は名詞でよい。

    | 書かない                             | 書く                                                                 |
    | ------------------------------------ | -------------------------------------------------------------------- |
    | 中心の寄りは 右 2.1cm です           | 矢は的の中心より 右に 2.1cm の所に集まっています                     |
    | はっきりした寄りがあります           | 矢が右に 2cm ずれて集まっています                                    |
    | ふだんの上下（±3 点）の中です        | この条件ではふだん ±3 点ほど上下するので、たまたまの差かもしれません |
    | 着弾中心のずれ                       | 矢の中心（的の中心から ○cm）                                         |
    | 中央値の不確かさは見積もれていません | まん中の値にどのくらい幅があるかは、まだ分かりません                 |
    | 実測との当てはまりは確かめられません | もう 1距離記録すると、合っているか確かめられます                     |
    | 動かさない／保留／判定できない       | そのまま／まだ動かさない／まだ分かりません                           |

## 4. 統計と不確かさの置き場所

正直さは変えない。変えるのは、置き場所と言葉。

- **本文（1行目）**: ふつうの言葉で、結論を言う。
- **根拠（2行目、うすい字）**: 何と比べたか（何回・いつからいつ・どの条件）を短く。「対象:」という書き出しはやめる。
- **「詳しく」（たたんである）**: 区間、標準偏差、検定、計算の方法。読みたい人だけが開く。統計の言葉はここでは使ってよい。

本文で使う言い換え:

| これまで                      | これから                                                                                           |
| ----------------------------- | -------------------------------------------------------------------------------------------------- |
| 95%区間 ±1.2cm                | ±1.2cm ほどの幅があります                                                                          |
| 回ごとの標準偏差は 3.1 点     | ふだんは ±3 点ほど上下します                                                                       |
| 差はその範囲内です            | ふだん ±3 点ほど上下するので、たまたまの差かもしれません                                           |
| 差はそれより大きい値です      | ふだん ±3 点ほど上下します。今回の差はそれより大きい差です                                         |
| 中央値                        | まん中の値（本文では「ふつうは 2.8 秒」のように言う）                                              |
| 測定のゆれ                    | カメラで測るときのぶれ                                                                             |
| 測定のゆれと区別できません    | ほぼ同じです（カメラで分かる細かさより小さい違い）                                                 |
| 偶然でこれだけずれる確率は 2% | 本文には書かない。「詳しく」に「サイトが合っていても、たまたまこれだけ片側に集まる確率は 2% です」 |
| 外れ値候補                    | 大きく外れた矢                                                                                     |
| グループRMS                   | グルーピングの大きさ（半径 ○cm）                                                                   |
| 原因とは断定できません        | これが理由だとは言い切れません                                                                     |
| 〜のため、表示していません    | 〜になると見られます（いま ○回）                                                                   |

符号つきの数（+0.3 点、−0.3cm）は、文の中では言葉にする（「0.3 点高い」「0.3cm 小さくまとまりました」）。表の中の数字は符号のままでよい。

たたんだ中に出る文は、ソースの中で `voice:fold-begin` と `voice:fold-end` のコメントで囲むか、同じ文字列の中の `<details>` に書く。
`tools/check-voice.js` は、その外に統計の言葉があると失敗する。

### 「まだ分からない」の言い方

理由を責めずに、あと何があれば分かるかを言う。

- 「同じ条件の記録が 3回になると、平均と比べられます（いま 2回）。」
- 「まだ矢が少なく、中心がはっきりしません。あと 1〜2エンド打ってから見直してください。」
- 「点数だけの記録なので、矢の位置はありません。」

## 5. 場面ごとの書き方

**データが消えるかもしれない場面**（バックアップ・読み込み・ゴミ箱を空にする・ブラウザのデータ消去）:
落ち着いて、はっきり、具体的に。何が消えるか、元に戻せるか、先に何をすればいいか、の3つを必ず書く。
ここだけは短くすることより正確さを優先する。「ゴミ箱へ移す」（戻せる）と「完全に消す」（戻せない）を言い分ける。
いまの設定画面の警告文は、この決まりをすでに満たしているので、ほぼそのまま残す。

**空の画面**: いまは何もないこと、何をすればここに出るか、を1〜2文で。ボタンを1つ。

**エラー**: 何が起きたか（1文）、記録は無事か、次にどうするか。機械の言葉（WebAssembly、ブリッジ、一意に特定）は書かない。

**確認の問いかけ**: 何が起きるかを言ってから、たずねる。ボタンは「はい／いいえ」ではなく、する動作の名前。

**お知らせ（短く出て消える表示）**: 起きたことだけ。「〜しました」。15字前後。

**サイトの目安**: 大きな字は 4つだけ。「右へ 1.5クリック」（動かす）、「そのまま」、「まだ動かさない」（動かす条件は満たすが、前の練習と向きが逆、または風の記録がある）、
「まだ分かりません」（矢の中心がまだ決まらない）。その下に、矢がどこに集まったかを動詞で 1文（「矢は的の中心より 右に 2.1cm・上に 0.4cm の所に集まっています（位置のある 36射）。」）、
理由を 1〜2文。区間・確率・動かす条件・量の出し方は「詳しく」と「計算の内訳」に。
「サイトはそのままで大丈夫です」は、動かす条件を満たさず、矢の中心も決まっている軸（計算の状態が none）にだけ使う。「大丈夫」をほかの所で使わない（検査がある）。
どの状態になるか・向き・量は計算のまま（`sightAdviceModel`）。言い換えで「動かしてよい」と読める範囲を広げない。

## 6. これからも書かないもの

- うそのほめ言葉、応援（この調子、ナイス、おめでとう、がんばりましょう、感嘆符）。
- 射手そのものの評価（上手・下手、良い射・悪い射、安定・不安定のラベル、信頼度 高/中/低）。
- 確かめていない助言を事実のように書くこと（「押し手が原因です」「リリースを直しましょう」）。
  アプリが言えるのは、記録から見えたことと、アプリの使い方（「あと1エンド打ってから見直す」「同じ場所から撮る」）まで。
- 「公式」「公認」という言い方。点数の決まりを述べるときは「WA のルールでは」と出どころを言う。
- 英語の飾り見出し。

これまでの規則から**残すもの**: うそを書かない、根拠のない助言をしない、不確かさを隠さない、何と比べたかを言う。
**変えるもの**: 根拠と不確かさを毎回1行目に並べるのをやめ、ふつうの言葉で1回だけ言う。くわしい数字は「詳しく」へ移す。
「〜しましょう」は引き続き使わない（アプリの操作の案内は「〜してください」「〜できます」）。

### 気をつけること

- **サイトの目安の意味を変えない。** 「動かす／まだ動かさない／そのまま／まだ分かりません」の条件と向き・量は計算のまま。言い換えで「動かしてよい」と読める範囲を広げない。
  数字（区間、確率）は消さずに「詳しく」へ。言葉の区切り（「よく合っています」など）を新しく作るときは、しきい値をオーナーと決める（いまは作っていない）。
- **データが消える場面の文は、短くするより正確に。** 何が消えるか・戻せるか・先にすることの3つを欠かさない。「控え」（端末の中の写し）と「バックアップ」（書き出したファイル）を取り違えない。
- **「たまたまの差かもしれません」を言いすぎない。** ふだんの幅の中にあるときだけ使う。外にあるときは「それより大きい差です」と言い、理由までは言わない。
- **保存してある値は触らない。** 選択肢の名前を変えるときは、表示の言い換えで済ませるか、古い値も読めるようにする。
- **ボタンや欄の名前で要素を探しているテスト**が多い。文言と一緒に直すが、`data-testid` は変えない。
- **長さ。** 親切にすると長くなりやすい。本文は1〜2文まで。iPhone の幅（375・320）で折り返しを確かめる。
- 表示が変わるので、公開するときは版を上げる（公開はオーナーの承認後）。
