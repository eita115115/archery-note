# グルーピング統計 grouping-v3 の仕様

ユーザーの提案（A: 全射 RMS を正式指標、B: MCD で外れ値候補を除いた RMS、C: MCD によるロバスト RMS、旧方式は比較用に保持）を、
統計設計の担当（Fable）が検討して確定した仕様。実装はこの仕様に従う。数値の根拠は試作シミュレーション
（xoshiro128\*\*、Marsaglia の極座標法、帰無 6,000〜20,000 回・検出力 1,000〜4,000 回）。

## 1. 提案への講評と決定

正しい点: A を正式指標にする／B・C は比較用に限る／独自の重み付けをやめる／旧方式を比較用に残す。

訂正した点:

1. 素朴な MCD の χ² しきい値は外れ値判定に使えない。家族単位 1% に合わせたしきい値は d² ≈ 259（n=6）、100（n=12）、
   32（n=36）となり（Bonferroni の χ² なら 13〜16）、8σ の矢の検出が 14%（n=6）・41%（n=12）・86%（n=24）まで落ちる。
2. 現行の「1 本ずつ除く逐次検定」は、同じ場所にまとまった外れ矢に完全に隠される（2 本・12σ・n=8〜24 で検出 0%）。
   最初の検定で有意にならないと止まるため。
3. B の決定: MCD が候補とその順位を出し、既存の厳密な F 検定で判定する。Rosner 型に k 段すべてを実行し、最後に有意だった段までを
   外れ値候補とする（Caroni & Prescott 1992, Appl. Statist. 41:355 の逐次 Wilks 手順を MCD の順位で行う）。
   1 本の外れ矢の検出力は現行と同じ。8σ の 3 本のまとまり: n=12 で 76%（1 本除外の順位なら 3%）、n=24 で 100%・巻き添え 1%。
   正規データで何か 1 本でも除く回の割合は 0.9〜1.7%。
4. B は何かを除いた時点で構造的に小さく出るため、一貫性係数をかけず「参考（記述統計）」と表示する。正規データでは約 99% の回で A と一致する。
5. C は B と同じものにしない。C は再重み付け MCD（RMCD）の共分散に一貫性係数と小標本係数をかけた「まとまっている矢のばらつき」の推定。
   この本数では χ² 漸近は成り立たない（Hardin & Rocke 2005; Pison, Van Aelst & Willems 2002）。
6. アルゴリズム: n ≤ 16 は全組み合わせを列挙（厳密 MCD）、それより多いと正準順に並べ替えた後、固定シードの C ステップ。
   乱数の初期値を使う FAST-MCD は決定的でも入力順に不変でもない。
7. B と C は 6 本以上。6 本未満は B = A、C はなし。
8. Huber や Beaton–Tukey の M 推定の重みは使わない（背景としてのみ引用）。

## 2. 定義

### A（正式）: 全射

- 標本平均、S = SS/(n−1)、`rr_A = sqrt(sxx + syy)`。
- RMS の 95% 区間（n ≥ 6、2 変量正規、Satterthwaite）: `nu = (n−1)(sxx+syy)² / (sxx² + syy² + 2 sxy²)`、
  `lo = rr·sqrt(nu/χ²(nu, 0.975))`、`hi = rr·sqrt(nu/χ²(nu, 0.025))`。χ² は Wilson–Hilferty 近似
  `χ²(nu, p) = nu(1 − 2/(9nu) + z·sqrt(2/(9nu)))³`。
- CEP や平均半径などの指標は増やさない（研究者の自由度を増やすだけで、座標は出力できる）。

### 生 MCD

`h = ceil(0.75n)`。行列式が最小の h 点の部分集合 H\*、`T0 = mean(H*)`、`S0 = SS(H*)/h`、
`S_raw = C75 · mraw(n) · S0`、`C75 = 0.75 / (1 − 0.25(1 + ln 4)) = 1.859075`（一般式 `c = a / F_χ²4(q_a)`、Croux & Haesbroeck 1999）。

### C（参考）: 再重み付け MCD

`(T0, S_raw)` からのマハラノビス距離² が `QC = −2 ln 0.025 = 7.377759` 以下の点だけで `T1 = 平均`、`S1 = SS/(m−1)`、
`S_C = CRW · mrw(n) · S1`、`CRW = 0.975 / (1 − 0.025(1 − ln 0.025)) = 1.104468`、`rr_C = sqrt(trace S_C)`。
6 本未満・縮退・m < 3 ならなし。

### B（参考）: 外れ値候補を除く

`(T1, S_C)` からの距離² の大きい順（同順位は正準順）に、最大 `k = n − h` 本を順に除きながら、各段で 1 本除外の厳密 F 検定
（`p < 0.01/残り本数`）を行う。最後に有意だった段までを外れ値候補とし、残りの標本統計を B とする。C がなければ除かない。

## 3. アルゴリズムと係数表

- 正準順: 全点の古典的マハラノビス距離²の昇順、同値は x、y の順（アフィン変換と入力順に不変）。
- n ≤ 16: 除く k 点の組み合わせをすべて列挙し、行列式が最小の部分集合（同値は先勝ち）。
- n > 16: xoshiro128\*\*（splitmix32 でシード 0x4D434431、呼び出しごとに再初期化）。開始点は正準順の先頭 h 点と、
  無作為な 3 点 ×24。各 2 回の C ステップ後、行列式の小さい 3 つを収束（最大 50 回）まで続ける。
- `MCD_MRAW` と `MCD_MRW` は `tools/gen-mcd-tables.js` で生成する（n=6〜72 は 1 本刻み、以降 84, 96, 108, 120, 144, 150。
  n ≤ 30 は 20 万回、それ以上は 10 万回。xoshiro128\*\*、シード 20261112+n と 20261112+1000+n、N(0, I)）。
  h=ceil(0.75n) の切り上げで本数を 4 で割った余りごとに係数がのこぎり状に上下するため、検証で 31〜47 本の補間に最大約 1.2%
  （RMS）の偏りが見つかり、72 本までは補間しないよう 1 本刻みにした。
  `mraw = 2 / (C75 · mean(trace S0))`、`mrw = 2 / (CRW · mean(trace S1))`（mraw 適用後）。表にない n は 1/n で線形補間、
  n > 150 は (1/150, 値) と (0, 1) の間で補間。

## 4. 利用先

| 利用先                                                                                                                                                         | 使う統計                                     |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| 表示する中心・RMS・σ・楕円、着弾図の十字と RMS 円、分析の推移・成長、今日の結果、用具比較、CSV の `group_*`                                                    | A                                            |
| サイト判定・提案、個人モデル、回帰の重み、サイト中心の履歴、散り方の診断（縦長・横長・斜め）、分析画面の「ズレだけ直す」助言と風別の偏り、用具比較の中心の移動 | B（`sightStats(st)`）                        |
| 判断信頼度                                                                                                                                                     | 標準誤差は B、「グルーピング広め」の理由は A |
| 着弾図の × 印                                                                                                                                                  | 外れ値候補                                   |

サイト判定に B を使う理由: 外れ矢でサイトを動かさないため。帰無での除外率は約 1% なので、Hotelling・閉検定・縮小推定の較正はそのまま有効。
C を推測に使うには実効サンプルサイズの補正が要るため使わない。

## 5. 旧方式

997db97 の `robustStats` を `legacyRobustStats` としてそのまま残す（既知の欠陥も直さない）。CSV 出力専用で画面には出さない。

## 6. CSV

既存の列の位置は変えず、末尾に `group_n, rms_ci95_lo_cm, rms_ci95_hi_cm, rms_df_eff, excl_n_flagged, excl_x_cm, excl_y_cm,
excl_rms_cm, robust_x_cm, robust_y_cm, robust_rms_cm, robust_n_weighted, legacy_x_cm, legacy_y_cm, legacy_rms_cm,
legacy_excluded, legacy_method, stats_version` を追加する。`group_x/y/rms` と `sigma_*` は A（以前は除外後）、
`excluded` は外れ値候補の本数になる（`excl_n_flagged` と同じ値。旧列の位置を保つために両方残す）。さらに末尾に
`group_cov_cm2, excl_sigma_x_cm, excl_sigma_y_cm, robust_sigma_x_cm, robust_sigma_y_cm` を追加し、A・B・C の楕円を
CSV から再構成できるようにした。

研究で使うときの注意:

- 旧版の CSV の `group_*`・`sigma_*`・`excluded` は意味が違う（除外後の値）。`stats_version` が `grouping-v3` の行だけを比べる。
- `rms_ci95_*` は 2 変量正規を仮定した区間。外れ値候補がある回（`excl_n_flagged > 0`）では目安として扱う。
- `legacy_*` は旧方式をそのまま再現した値で、矢を記録した順番によって結果が変わる（記録順のまま計算している）。

## 7. 画面

主表示は「グルーピング半径 (RMS・全射)」。「詳しく」の中に、全射 RMS の 95% 区間、外れ値候補を除いた RMS（参考）、
ロバスト RMS（参考）、外れ値候補（図の × 印。全射 RMS には含み、サイト判断でのみ除外）を置く。外れ値候補がある回は
「サイト判断の中心（外れ値候補を除く）」も並べ、表示の中心（全射）とサイト判断の中心が違う理由が分かるようにする。
